This small friend is a Live2D model I originally made for practice. The completed model is setup to be used with VTube Studio, but should work with any Live2D compatible program. 
It includes two extra texture variations, a black cat version and a calico cat version, as well as a small guide to help you make your own edited textures!
If you would like to use the assets for rigging practice, you can also purchase the separated PSD to make that easier.
 *I have added the .cmo3 file as well, if you would like to look at or try editing the original rigging in the Live2D Cubism Editor!
